*[Конфигурация Настраиваем ввод и вывод файлов (97)]*

? 97.0 Здесь мы подробнее остановимся на конфигурации TypeScript и рассмотрим самые необходимые и часто встречающиеся опции.

? 97.1 Мы уже говорили в более ранних уроках, что для запуска компилятора из TypeScript в JavaScript мы можем использовать команду в консоли `tsc`, тогда из файла "index.ts" будет скомпилирован "index.js", который уже можно использовать для рабочего проекта и его деплоя. Настройки компиляции будут браться из файла "tsconfig.json". Также будут скомпилированы все TS-файлы из корневой директории в JS-файлы. Либо мы можем написать "tsc %имяфайла%" (указать конкретное имя TS-файла для компиляции), но тогда, чтобы применились опции из конфига, надо будет их прописать в команде в консоли, но это жутко неудобно и так почти никогда никто не делает.

? 97.2.0 Такого случая, чтобы все файлы лежали в корне проекта, кроме учебных и тестовых обычно не бывает, поэтому ознакомимся с первой опцией `files`, указывающей компилятору где брать TS-файлы для компиляции. Она указывается на топ-уровне конфига и является массивом файлов, которые надо включить в компиляцию (см. [97-config-ts/tsconfig.json]). 

Рассмотрим тему далее в файле конфига: [97-config-ts/tsconfig.json]

? 97.7 Ещё важно отметить, что компилятор можно запускать в режиме "слежения", чтобы не набираться `tsc` всякий раз вручную после каждого изменения, для этого нужно один раз ввести `tsc --watch`.
